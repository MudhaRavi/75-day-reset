# 75-Day Reset

A 75-day challenge app: daily quests, XP, levels, stats, titles, a vision board and a weight log.
Installable on iPhone as a home-screen web app. Data is stored on the device (localStorage).

Files: `index.html` (the app), `manifest.json` (name and icon), `sw.js` (offline support), icons.
To release an update: edit `index.html`, bump `CACHE` in `sw.js` (e.g. `reset75-v2`), push.
